# MatScale Project Roadmap

This document outlines the planned improvements and features for MatScale, the ultimate desk mat visualizer.

## ✅ Phase 1: Foundation & Community (In Progress)
- [x] Modern, responsive UI with Dark/Light mode.
- [x] Core visualization logic (mm, cm, inches).
- [x] Keyboard & Mouse peripherals.
- [x] QR Code for mobile cross-device viewing.
- [x] **Email Collection Form** (Stay updated on new features).
- [x] **Social Media Integration** (Follow the build).

## 🚀 Phase 2: User Experience & Sharing
- [ ] **URL Persistence**: Share your setup via a unique link (URL Params).
- [ ] **Export to Image**: Download your setup as a high-quality PNG/JPG.
- [ ] **Unit Auto-Correction**: Smart warnings if equipment is too large for the mat.
- [ ] **Equipment Library**: Add monitors, laptops, stream decks, and speakers.

## 🎨 Phase 3: Visual Fidelity & Customization
- [ ] **Mat Textures**: Leather, Felt, Cloth, and RGB animated edges.
- [ ] **Custom Gear Dimensions**: Allow users to input their specific gear size.
- [ ] **3D Perspective View**: Toggle between 2D top-down and a 3D isometric view.

## 🤝 Phase 4: Community & Marketplace
- [ ] **Setup Gallery**: User-submitted setup inspirations.
- [ ] **"Buy This Size"**: Direct links to popular mats matching the user's configuration.
